# ЛевКарго — сайт компанії вантажних перевезень

Односторінковий адаптивний сайт вигаданої львівської компанії вантажних перевезень «ЛевКарго».
Навчальний проєкт з курсу «Прикладне та Web-програмування» (Національний університет «Львівська політехніка»).

**Сайт онлайн:** https://НІКНЕЙМ.github.io/levcargo/

## Можливості

- Адаптивна верстка від 320 до 1920 px (desktop first, контрольні точки 1199 / 991 / 767 / 479 px)
- Випадаюче меню на ПК і доступне бургер-меню на смартфонах
- Перший екран з фоновим зображенням (WebP + JPEG) і секція з фоновим відео з лінивим завантаженням
- Форма заявки з перевіркою полів і надсиланням на пошту через [FormSubmit](https://formsubmit.co)
- Таблиця вартості доставки, яка на смартфоні перетворюється на картки
- UI-компоненти зі станами `:hover`, `:focus-visible`, `:active`, недоступний
- Стримані CSS-анімації з урахуванням `prefers-reduced-motion`

## Секції сторінки

1. Шапка з навігацією
2. Перший екран
3. Послуги
4. Автопарк
5. GPS-моніторинг (фонове відео)
6. Тарифи
7. Таблиця вартості доставки
8. Відгуки
9. Заявка і контакти
10. Футер

## Технології

- HTML5 (семантичні теги, форми, таблиці)
- CSS3 (змінні, Flexbox, медіа-запити, transition, @keyframes)
- JavaScript (бургер-меню, IntersectionObserver, перевірка та надсилання форми)
- Figma — макет для ПК і смартфона
- ffmpeg — стиснення відео (з 37,4 МБ до 1,1 МБ)

## Структура проєкту

```
levcargo/
├── index.html          # єдина сторінка сайту
├── README.md
├── css/
│   └── style.css       # усі стилі
├── js/
│   └── main.js         # меню, відео, форма, анімації появи
├── img/                # фото, фони, логотип
```

## Як запустити локально

Збирати нічого не потрібно: достатньо завантажити репозиторій і відкрити `index.html` у браузері.

```bash
git clone https://github.com/НІКНЕЙМ/levcargo.git
cd levcargo
```
